   • Resumen: ¿Cuál era el objetivo inicial?
Averiguar si era posible crear un conversor/compilador de archivos de Arduino (`.ino`) a binarios en formato Intel HEX (`.hex`) con un comando para transferirlos a la placa física, usando el lenguaje Rust, trabajando únicamente desde un teléfono Android con Termux y conectándolo con el lenguaje propio Salem.

---

1. Del código fuente al hardware (`.sl` / `.ino` $\rightarrow$ `.hex`):
   * El código que escribimos los humanos (en Salem o C++/Arduino) no lo entiende directamente el chip.
   * El compilador traduce ese texto a código máquina (instrucciones en ceros y unos).
    El formato Intel HEX (`.hex`) es un archivo de texto estándar que organiza esos ceros y unos en renglones con direcciones de memoria exactas y sumas de verificación (checksum*), listo para grabarse en la memoria flash del microcontrolador.

2. La limitación de Android y la solución con PRoot:
   * Android restringe muchas herramientas clásicas de desarrollo por seguridad.
   * Usando `proot-distro login debian`, creamos una «caja de herramientas» completa de Linux Debian dentro de Termux. Esto nos dio acceso al gestor de paquetes `apt` sin necesidad de rootear el teléfono ni tener una computadora de escritorio.

3. El problema de los certificados TLS/SSL:
   * Al descargar paquetes de Arduino en una instalación mínima de Linux, el sistema dio error de verificación de certificados (`certificate signed by unknown authority`).
   * Lo solucionamos instalando el paquete `ca-certificates`, lo que permitió a la herramienta autenticar las conexiones seguras HTTPS con los servidores oficiales de Arduino.

4. Compilación cruzada (Cross-compilation):
   * El teléfono tiene un procesador con arquitectura ARM64 (`aarch64`).
   * El microcontrolador de una placa Arduino Uno tiene un procesador AVR (ATmega328P).
   * Instalamos un compilador cruzado (`arduino:avr-gcc` y `arduino-cli`), lo que significa que un procesador ARM64 compila código pensado para ejecutarse en un chip AVR.

// Creado por Martín José Dalberto, Argentina, 2026.

// EMISOR INTEL HEX — ARDUINO SALEM
// ============================================================
// Convierte secuencias binarias en formato estándar Intel HEX (.hex)
// ============================================================

use std::fs::File;
use std::io::Write;
use std::path::Path;
use ihex::{Record, create_object_file_representation};

/// Escribe una secuencia de bytes en un archivo con formato Intel HEX.
///
/// * `datos_binarios`: Vector de bytes de las instrucciones o datos.
/// * `direccion_inicio`: Dirección base de memoria en el microcontrolador.
/// * `ruta_destino`: Archivo .hex donde se guardará el resultado.
pub fn escribir_intel_hex(
    datos_binarios: &[u8],
    direccion_inicio: u16,
    ruta_destino: &Path,
) -> Result<(), String> {
    let mut registros: Vec<Record> = Vec::new();
    let tamano_bloque: usize = 16; // 16 bytes por línea de registro

    for (indice, bloque) in datos_binarios.chunks(tamano_bloque).enumerate() {
        let desplazamiento = direccion_inicio
            .checked_add((indice * tamano_bloque) as u16)
            .ok_or_else(|| "Desbordamiento de dirección al generar registros HEX".to_string())?;

        registros.push(Record::Data {
            offset: desplazamiento,
            value: bloque.to_vec(),
        });
    }

    // Registro obligatorio de fin de archivo (EOF)
    registros.push(Record::EndOfFile);

    let contenido_hex = create_object_file_representation(&registros)
        .map_err(|error| format!("Error al codificar registros Intel HEX: {error}"))?;

    let mut archivo = File::create(ruta_destino)
        .map_err(|error| format!("Error creando archivo {}: {error}", ruta_destino.display()))?;

    archivo
        .write_all(contenido_hex.as_bytes())
        .map_err(|error| format!("Error escribiendo en {}: {error}", ruta_destino.display()))?;

    println!(
        "[Arduino-HEX] Archivo generado con éxito: {}",
        ruta_destino.display()
    );
    Ok(())
}

use std::fs;
use std::path::{Path, PathBuf};
use std::process::Command;

/// Modo de transferencia hacia la placa física.
pub enum ModoTransferencia {
    /// Placas que montan como disco o pendrive por USB OTG.
    CopiaDirectaUsb(PathBuf),
    /// Subida por puerto serie usando Termux USB o avrdude.
    PuertoSerieTermux(String),
}

/// Copia un archivo .hex directamente al punto de montaje de la placa por USB OTG.
pub fn copiar_a_placa_otg(ruta_hex: &Path, punto_montaje_placa: &Path) -> Result<(), String> {
    if !ruta_hex.exists() {
        return Err(format!("El archivo HEX no existe: {}", ruta_hex.display()));
    }
    if !punto_montaje_placa.is_dir() {
        return Err(format!(
            "El punto de montaje de la placa no es accesible: {}",
            punto_montaje_placa.display()
        ));
    }

    let nombre_archivo = ruta_hex
        .file_name()
        .ok_or_else(|| "Nombre de archivo no válido".to_string())?;

    let destino = punto_montaje_placa.join(nombre_archivo);

    println!(
        "[Salem-Cargador] Copiando firmware a {}...",
        destino.display()
    );

    fs::copy(ruta_hex, &destino)
        .map_err(|error| format!("Fallo al copiar firmware a la placa: {error}"))?;

    println!("[Salem-Cargador] ✅ Firmware copiado exitosamente a la placa.");
    Ok(())
}

/// Ejecuta la subida a un Arduino clásico utilizando avrdude dentro de Termux.
pub fn subir_con_avrdude_termux(
    ruta_hex: &Path,
    microcontrolador: &str, // ej: "atmega328p"
    programador: &str,      // ej: "arduino"
    puerto_o_fd: &str,      // ej: "/dev/ttyUSB0" o dispositivo expuesto por termux-usb
    velocidad_baudios: u32, // ej: 115200
) -> Result<(), String> {
    println!(
        "[Salem-Cargador] Iniciando subida con avrdude a {} a {} baudios...",
        microcontrolador, velocidad_baudios
    );

    let salida = Command::new("avrdude")
        .args([
            "-p", microcontrolador,
            "-c", programador,
            "-P", puerto_o_fd,
            "-b", &velocidad_baudios.to_string(),
            "-D", // Evita borrado previo innecesario en bootloaders
            "-U", &format!("flash:w:{}:i", ruta_hex.display()),
        ])
        .output()
        .map_err(|error| format!("No se pudo invocar avrdude: {error}. ¿Está instalado en Termux?"))?;

    if !salida.status.success() {
        let detalle = String::from_utf8_lossy(&salida.stderr);
        return Err(format!("Fallo en la subida con avrdude:\n{detalle}"));
    }

    println!("[Salem-Cargador] ✅ Grabación completada con éxito en la placa.");
    Ok(())
}
